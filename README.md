# Skeasy links

Small public pages for the Skeasy ski app.

- `/meet/` opens a "meet me here" spot in Skeasy. The spot travels after the `#` in the
  link, so it is never sent to this site: the page reads it on the phone and hands it to the app.
- `/privacy/` is the app's privacy policy (linked from the App Store page and inside the app).
  Source text: the project's `launch/privacy-policy.md`; regenerate this page when it changes.
- `/support/` is the App Store support page.
